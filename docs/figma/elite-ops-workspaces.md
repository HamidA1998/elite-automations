# Elite Ops Workspace Specs

This file defines the target Figma layouts for each core workspace and inspector tabs.

## Modes

## EA (Executive)

- Objective: strategic visibility and decision prioritization.
- Primary blocks:
  - Weighted pipeline, readiness, 24h activity KPIs.
  - Revenue scoreboard.
  - Stage distribution and area/type pipeline mix.
  - Priority guidance cards with direct actions.

## CRM

- Objective: account system of record.
- Primary blocks:
  - Searchable account ledger.
  - Health and stage views.
  - Commercial state and outreach readiness.
  - Quick open into inspector.

## AI

- Objective: project intelligence + blocker management.
- Primary blocks:
  - Completion radar/checkpoint coverage.
  - Blocker queue with recommended action.
  - Follow-up pressure list.
  - Cross-account memory index.

## Ops

- Objective: daily execution and throughput control.
- Primary blocks:
  - Daily batch planner (top 10 actions).
  - Cold call command center.
  - Live event feed.
  - Stage kanban with drag and stage-change logging.

## Vid

- Objective: creative asset readiness and review.
- Primary blocks:
  - Production table with readiness statuses.
  - Render queue controls.
  - 2x2 asset preview (image/demo/video/email).
  - Creative checkpoints checklist.

## Mail

- Objective: project-linked mailbox operation.
- Primary blocks:
  - Drafts list with expanded full-body preview.
  - Sent history linked to timeline events.
  - Reply queue linked to account state.
  - Mail performance metrics.

## Pay

- Objective: live commercial visibility.
- Primary blocks:
  - Collected vs pipeline value.
  - Average deal and won-count cards.
  - Revenue ledger with filters/sorting.
  - Cashflow bars for collected/pipeline/outstanding.

## Inspector Tabs

## Overview

- Editable account identity and status fields.
- Creative assets panel.
- Website analysis matrix + strengths/weaknesses + top problems.

## Contacts

- Full stakeholder capture form.
- Contact cards with preference and status intelligence.

## Timeline

- Quick-log actions with metadata entry.
- Full reverse-chronological event history.

## Tasks

- Per-account task creation and grouped open/completed lists.
- Overdue signaling.

## Proposal

- Full proposal builder.
- Proposal history and weighted-value logic.

## Memory

- Structured account memory fields for operator and AI context.

## Notes

- Rich free-form notes with searchable history and pinning.

## Interaction Rules

- Cmd/Ctrl+K command palette for cross-app actions and navigation.
- Inspector must be collapsible, resizable, and never block main work when closed.
- No dead-end empty states: every empty block includes a primary next action.
